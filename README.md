# 한남대학교 AI융합학과 2027 입시 예측

ZIP을 풀고 predict.py가 있는 폴더에서 다음 명령을 실행한다. Python 3.12를 기준으로 작성했다.

```shell
python -m pip install -r requirements.txt
python predict.py
python -m unittest -v
```

이미 계산한 results/2027_전항목.csv는 Excel에서 열 수 있다. value가 최종 출력이고 RF와 Ridge는 보정 전 개별 모델값이다. n은 방법에 사용한 관측 행 수, 검증건수는 같은 모집 범위·전형·항목에서 실제값과 비교한 건수다. MAE는 평균 절대오차이며 해당 항목의 단위로 읽는다. 빈칸은 해당 없음 또는 자료 부족을 뜻한다. 연도별_검증.csv에는 사후 대조에 사용한 actual과 예측값이 있다. SHAP은 일반전형 최종 평균에 대한 RF 설명이다. 설명을 생략하려면 python predict.py --no-shap으로 실행한다.

## 입력과 결과 해석

- data에는 제공한 CSV 6개와 conditions.csv가 있다. 수시 2026년 마감 경쟁률은 지원÷모집을 소수 둘째 자리까지 반영한다. 2027 수시 모집인원·지원인원·경쟁률은 확정된 입력이다. 2020·2021 연도 배치와 2025년 지역인재교과우수자 모집·충원은 새 CSV 표기대로 사용했다.
- 수시 4전형을 함께 학습하되 전형을 범주 변수로 구별한다. FirsMax/Min은 최초 최고/최저, FinalMax/Avg는 최종 최고/평균으로 해석한다. 과거 지역인재전형은 한남인재Ⅱ에 연결한 가정이며 최근 3년 자료가 없다. 한남인재Ⅱ는 올해 경쟁률이 과거 수시 범위도 넘어 다른 전형보다 불확실하다.
- 수시 성적과 예비순위의 대표값은 RF와 Ridge의 단순평균이다. 평균에 대한 성능 우위가 입증된 조합은 아니다. 등급은 1~9 사이, 예비순위는 0~(지원−모집) 사이 정수로 제한한다. 공시된 과거 경쟁률의 반올림 때문에 과거 예비순위 상한은 근사값이다. 첫해 등 과거 자료가 부족한 시점은 평가에서 제외한다.
- FinalCut은 CutCriteria에 따라 70%와 80%를 구분한다. 2027 평균 예측에 동일 전형·동일 기준의 과거 (컷−평균) 평균을 더한다. 70%는 최대 2년으로 추정하고 검증은 전형별 최대 1건이다. 80%는 과거 방식이 지속됐을 때의 별도 참고값이다. 서로 다른 연도 구성을 사용하므로 두 값을 같은 합격자 집단의 동시 분위수로 해석할 수 없다. 예컨대 한남인재Ⅰ의 80% 참고값은 70% 추정보다 낮다. 최종 최저등급은 원자료에 없다.
- 정시는 학과/전체 파일, Normal/Rural을 각각 분리한다. 관측이 짧아 최대 최근 3개 유효 관측연도의 중앙값을 사용한다. 학과 일반의 모집인원은 3명(수시 이월 전)으로 고정한다. 나머지는 모집인원도 추정한다. 예측 인원은 정수 반올림하며 경쟁률은 최종 인원으로 다시 계산한다. 이 방식은 기존 정시 RF·Ridge와 다르다. 농어촌 2026년 빈칸은 제외하며 모집 지속 여부는 가정이다. 전체 파일 결과는 파일에 기록된 모집군·유형의 범위에 해당한다. 정시에는 등급 자료가 없다.
- Year, Group, Type, CutCriteria는 학년도, 모집군, 전형, 컷 정의를 지정한다. Group은 A/B/C(가/나/다), 정시 학과 일반은 다군, 나머지 모집군은 최근 관측 기준이다.
- 검증은 예측 연도 이전 기록만 학습한다. 수시의 검증 연도 모집인원과 마감 경쟁률은 당시 원서 마감 후 예측하는 조건이다. 정시 학과 일반은 검증 연도의 모집인원이 알려진 조건이다. 과거 예측 111건은 서로 다른 단위의 항목을 합한 행 수다.
